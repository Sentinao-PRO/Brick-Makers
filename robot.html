Robot Overview

Our robot is designed for optimal performance in the FIRST Tech Challenge competition. Built with precision and innovation, it combines mechanical excellence with advanced programming capabilities.

Construction Stages

01

Design & Planning

Our team started with detailed CAD designs and strategic planning to ensure optimal robot performance.

02

Mechanical Construction

Precision assembly of the chassis, drivetrain, and mechanical systems using high-quality components.

03

Programming & Software

We program our robot in Java using the FTC SDK. Our codebase includes autonomous routines, teleoperation controls, and sensor integration.

Main Technologies:

  • Language: Java
  • Main Classes: OpMode, LinearOpMode, Hardware Configuration
  • SDK: FTC Robot Controller SDK
  • Control System: REV Robotics Control Hub
  • Sensors: IMU, Distance Sensors
